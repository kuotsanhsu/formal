## Planned Teaching Protocol

- Before each stage, ask the user to clarify or approve the local plan.

- Track side ideas separately so tangents do not erase the main line.

## Candidate Stages

These are provisional and should not yet be treated as the final course:

- Stage 0: calibrate background and choose a proof route.
- Stage 1: mathematical logic foundations and formal syntax.
- Stage 2: arithmetic, computability, and primitive recursive functions.
- Stage 3: Gödel coding and syntactic operations.
- Stage 4: representability in arithmetic.
- Stage 5: provability, diagonalization, and fixed points.
- Stage 6: first incompleteness theorem.
- Stage 7: comparison with mechanized proofs and possible refinements.
